## 🚀 Featured Projects

### 🏃 SprintDesk — Sprint Management Dashboard

<a href="https://github.com/saquibkhan-dev/Sprint-Desk">
  <img src="https://img.shields.io/badge/View%20Project-38BDF8?style=for-the-badge&logo=github&logoColor=white" />
</a>

Full-stack-style sprint management dashboard featuring a drag-and-drop Kanban board with keyboard accessibility, Bearer token authentication with silent refresh, sprint analytics, and real-time notifications.

**Tech Stack**

`React 19` `TypeScript` `Vite` `TanStack Query` `Zustand` `Tailwind CSS` `dnd-kit` `Recharts`

---

### 🔐 Approval Workflow System with Audit Logs

<a href="https://github.com/saquibkhan-dev/Approval-Workflow-System-with-Audit-Logs">
  <img src="https://img.shields.io/badge/View%20Project-38BDF8?style=for-the-badge&logo=github&logoColor=white" />
</a>

Role-based approval platform supporting Admin, Approver and Requester workflows with protected routes and a normalized MySQL schema.

Includes live audit logs, real-time approval status updates, API validation with Postman and automated Jest testing.

**Tech Stack**

`React.js` `Node.js` `Express.js` `MySQL` `Jest` `Postman`

---

### 🧾 Invoice Chaser — Freelance Invoice Management SaaS

<a href="https://github.com/saquibkhan-dev/Invoice-Chaser">
  <img src="https://img.shields.io/badge/View%20Project-38BDF8?style=for-the-badge&logo=github&logoColor=white" />
</a>

Freelance invoice management SaaS MVP for creating invoices, tracking payment states from Draft → Sent → Overdue → Paid, and monitoring revenue through a live dashboard.

Uses Supabase Auth and Row Level Security for per-user data isolation, with Edge Functions for automatic overdue detection and invoice PDF generation.

**Tech Stack**

`React` `Vite` `Tailwind CSS` `Supabase` `PostgreSQL` `Edge Functions` `PDF Generation`
